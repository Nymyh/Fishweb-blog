What is Fish?

Fish is a personal blog about Linux, free software, open source, tutorials, software recommendations, and other topics. The page has no other function beyond that.

Fish is a open source website?

Yes! Fish is a open source website, the source code is under the license AGPLv3 and the content on the page uses a different license. You can read that at the top of the page or right here, below the fish logo.

Why Fish look like this?

It’s my own personal choice: I prefer minimalist websites that use only pure HTML and very little CSS.
